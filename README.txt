EC Ganadería V5 — PWA instalable

Esta carpeta ya contiene la aplicación web instalable:
- manifest.webmanifest
- service worker para uso offline
- icono de la app
- evaluaciones editables
- historial local
- planilla A4 apaisada para guardar como PDF

IMPORTANTE:
Para que Android permita instalarla como una app real, estos archivos deben publicarse en un sitio HTTPS.
Abrir index.html directamente desde el ZIP sirve para probar, pero no activa correctamente la instalación/offline.

Una vez publicada:
1. Abrir la URL en Chrome en Android.
2. Menú ⋮ > Instalar app (o Agregar a pantalla principal).
3. EC Ganadería queda con icono propio y abre sin barra del navegador.

Los datos de esta versión se guardan localmente en el dispositivo/navegador.
